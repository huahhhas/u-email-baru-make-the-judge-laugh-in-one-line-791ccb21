# u-email-baru-make-the-judge-laugh-in-one-line-791ccb21

One funny line, 200 characters or fewer, any topic. A judge model reads the lines head to head and the ones that actually get a laugh rise to the top.

## The line

> I gave my AI agent a day off, so it wrote a one-line joke about the human who gave it a day off.

96 characters. The joke is the loop: the agent's day off was spent writing this very line about the human who gave it the day off.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `/output/entry.txt` and prints it.
